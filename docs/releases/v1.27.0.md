# Rutba Office 1.27.0 beta — in the works

A caption numbered by a field in Rutba Word; a watch window in Worksheets;
find and replace across a deck in Presentation; and in Mail a signature per
account, send later, and automatic replies. Not yet released: this file gathers what has landed on the
branch since 1.26.0.

## Rutba Word

- **Insert → Caption.** A dialog offers Figure, Table or Equation and a
  line of text, previews "Figure 3: …" before OK is pressed, and inserts a
  new paragraph after the caret's — styled "Caption" (written once, italic,
  9pt, space after, the way Word writes one on a document that never had
  the style), the label, a SEQ field for its running number, then the
  words. The number is a COMPLEX field — `w:fldChar` begin/separate/end
  around ` SEQ Figure \* ARABIC `, the shape Word itself writes for a
  caption, unlike a cross-reference's simpler `w:fldSimple` — shaded on the
  page exactly as a REF field is. Update Fields (F9, on the References tab)
  now renumbers every label's captions from where they sit in the document,
  the same pass that refreshes a REF: a caption inserted ahead of others
  with the same label, or one deleted, leaves the rest right once Update
  Fields runs. The button was greyed out ("A caption is a SEQ field; fields
  are not written yet").

## Worksheets

- **Formulas → Watch Window.** The button now opens a pane docked along the
  bottom of the grid — a table, one row per watched cell: Sheet, Cell,
  Value and Formula. Add Watch adds every cell of the current selection,
  not only the active one; a row's own × takes it off, and Delete Watch
  removes whichever row is selected; a double-click on a row goes to that
  cell, switching sheet first when it is on another one. Every row is
  live: read straight off the calculation on each frame, the same way
  Error Checking rereads its list, so editing a precedent anywhere in the
  workbook moves the watched value at once, with nothing telling the pane
  to refresh. The list is kept for as long as the workbook stays open —
  closing the pane or switching sheets never loses it — but it is never
  written to the file: Excel does not keep its own watch window in the
  workbook either, and this one follows suit. The button was greyed out.

## Presentation

- **Home → Find (Ctrl+F) and Replace (Ctrl+H).** The ribbon's Find and
  Replace buttons now open a small pane at the stage's own top right, the
  way Word's find pane sits over the page rather than a dialog covering
  the slide. A word typed into it is found across every shape's paragraphs
  on every slide — text boxes, placeholders and table cells — read as "n
  of m", Next and Previous walking the hits in slide order and landing on
  the hit's own slide and shape each time; Match case narrows the search.
  Replace rewrites the current hit, Replace All every hit at once, each
  keeping its run's own look — bold, italic, colour, font, size — since
  only the words inside the run change. A match that would straddle two
  runs is not offered: the boundary between two runs is where their look
  can change, and rewriting across it would either lose the second run's
  formatting or have to invent a blend of the two, so only a match sitting
  inside a single run is one Replace can rewrite cleanly. The button was
  greyed out (`docs/GAPS.md`: "find and replace across a deck").

## Mail

- **A signature per account.** Set from that account's own settings —
  Folder → Signature — a signature is plain text, kept on the account
  alongside its name and its servers rather than in a preference every
  account shares. A new message carries it at the end, after a blank
  line and the "-- " line mail readers use to tell a signature from the
  words above it; a reply or forward puts the same block above the
  quoted or forwarded message instead, below the cursor rather than
  under it. Switching the From account in an open message swaps the
  block for the one that account keeps — but only when it is still
  exactly what was inserted; a signature already edited, or a body with
  nothing inserted to begin with, is left alone. An account with no
  signature has nothing added.

- **Send later, and an Outbox that is a real place.** Send in a new
  message now offers Send later: later today, tomorrow morning at 8, Monday
  morning at 8, or a date and time of your own, all in the computer's own
  time zone. The message waits in an Outbox kept on this computer, listed
  in the folder list with each message's send time; opening one offers
  Edit (back into the message window), Send now, or Cancel, which puts it
  in Drafts rather than throwing it away. It is sent when its time comes
  while Rutba Office is running, and anything that fell due while it was
  closed goes the moment it opens again; the window says so. A send that
  fails stays in the Outbox with the server's answer beside it and is tried
  again every five minutes, or at once with Retry, where before it was
  moved to Drafts after three tries without a word.

- **Automatic replies, per account.** Folder → Out of office turns them on
  for the account, with an optional start and end, a subject ("Automatic
  reply: " and the original subject unless you write your own), the
  message, and "only reply to people in my contacts". A banner across the
  window says which account is answering on its own, with Turn off beside
  it. A reply keeps the rules that stop two away messages mailing each
  other forever (RFC 3834): nothing already automatic, no bulk or list
  mail, no no-reply or mailer-daemon address and never the account's own
  address gets one, and each sender hears from it once while it is on. The
  reply says what it is (`Auto-Submitted: auto-replied`) and threads under
  the message it answers. Replies go out while Rutba Office is running:
  holding them on the server (Gmail's vacation responder, Microsoft 365's
  automatic replies) needs a sign-in permission this version does not ask
  for, and the dialog says so rather than promising more.

## Proven, not promised

- Nine engine tests in `tests/word-captions.test.js`: a caption lands as
  its own paragraph, styled Caption, right after the caret's; three
  captions of the same label number themselves 1, 2, 3 in document order;
  two labels (Figure, Table) count independently; deleting the middle of
  three captions and calling Update Fields renumbers the one after it;
  the SEQ field's XML matches Word's own form byte-for-byte, and reads
  back through the same field-parsing path a REF uses, shaded the same
  way; the Caption style is written once however many captions follow;
  a caption survives a save and reopen with its field kept, not frozen
  as inert text — deleting one in the reopened copy and updating fields
  still renumbers what is left; a caption paragraph built by hand, the
  way one from Word itself would read, is read as a field and renumbered
  correctly alongside one this engine inserted; and undo after inserting
  a caption takes the whole paragraph back off. The new `captions` window
  check (`RUTBA_VERIFY_ONLY=captions`) places the caret in the fixture,
  inserts a Figure caption from the ribbon dialog, reads "Figure 1: …" on
  the page with its number shaded like any field, inserts a second and
  reads "Figure 2: …", then saves and reads the SEQ field's complex-field
  shape out of the file.

- Six engine tests in `tests/sheet-watch.test.js`: adding a cell already
  on the list, or twice in one call, leaves it once; new refs land after
  what was already there, in the order given; removing one watch leaves
  the rest in place, in order, and a ref nobody is watching changes
  nothing; a resolved row carries its sheet, reference, live value and
  formula text (`null` for a plain value); a precedent edited after a
  watch is added moves its value on the next read, with nothing telling
  it to refresh; and a watch on a sheet since removed from the workbook
  drops out of the resolved list rather than throwing. Five window checks
  in the new `watch` block (`RUTBA_VERIFY_ONLY=watch`): select a formula
  cell already in the sample workbook, open the pane, Add Watch, and read
  its row's sheet, value and formula; edit the precedent the formula
  reads through the ordinary engine ops and watch the row follow it live;
  take the watch off with the row's own × and see it go; and Close turns
  the pane off, the button lifting with it, and the window reports
  nothing throughout.

- Nine engine tests in `tests/deck-find.test.js`: two cover the deck's
  existing shape-by-shape `findText`/`replaceText`; seven new ones cover
  `find`, `replace` and `replaceAll` — hits across two slides in slide,
  shape, paragraph and run order; case sensitivity on and off; no hits for
  a word the deck does not hold; a single replace keeping its run's bold,
  italic and size while the rest of the words are untouched; Replace All's
  count and the rewritten words surviving three hits inside one run
  without one replacement's length throwing off the offsets of the next;
  a hit inside a table cell, carrying its row and column, found and
  replaced there too; and find, replace and replaceAll all surviving a
  save. Seven window checks in the `deckfind` block
  (`RUTBA_VERIFY_ONLY=deckfind`, aliased from the existing `find` block):
  the pane opens from Ctrl+H or the ribbon's Replace button and reads "1
  of 2" on typing a word, landing on its first hit's slide; Next moves to
  the next hit's slide, the count following it; Match case narrows the
  search to nothing for a query only case tells apart; Replace All rewrites
  both hits and reports the count; the saved file carries the replaced
  words; the deck is left exactly as the check found it; and the window
  reports nothing.

- Seven engine tests in `tests/mail-signature.test.js`: a new message
  gets the signature at the end after a blank line and the "-- " line, a
  reply puts it above the quote and below the cursor, an empty
  signature is a no-op for a new message and a reply alike, switching
  accounts swaps the block — at the end of a new message and above a
  reply's quote — when it is still exactly what was inserted, an edited
  signature is left alone on the next switch, and there is nothing to
  swap when the old account carried no signature. One window check in
  the new `signature` block (`RUTBA_VERIFY_ONLY=signature`) sets a
  signature from the seeded account's own Folder → Signature dialog,
  opens a new message and reads its plain-text body for the blank
  line, the "-- " line and the signature, then opens a reply and finds
  the same block above the quote, and the window reports nothing.

- Eight engine tests in `tests/mail-sendlater.test.js` and eight in
  `tests/mail-ooo.test.js`. Send later: the choices fall where they say,
  Monday morning included across a weekend; the Outbox sends only what is
  due, oldest first, and leaves the rest; a failed send stays with its
  error and goes again on the next pass; Cancel takes it off the queue
  unsent; the queue survives a restart, and what fell due while closed
  goes at start-up. Automatic replies: each of the RFC 3834 skips, one
  reply per sender while it is on, the start and end honoured to the
  minute on either side, contacts-only, the reply's headers, and turning
  it on again starting the list of who has been answered afresh. The mail
  service now takes its clock and its sending transport as arguments,
  which is what lets all sixteen run with no timer and no network. Two new
  window blocks: `sendlater` (`RUTBA_VERIFY_ONLY=sendlater`) sends a
  message later from the message window, reads it in the Outbox with its
  time, presses Send now and finds it gone from the Outbox and in Sent;
  `ooo` (`RUTBA_VERIFY_ONLY=ooo`) turns automatic replies on from the
  account's dialog, reads the banner, delivers a message through a
  stand-in for new mail arriving (it refuses to run outside a check) and
  finds exactly one reply sent, with its headers, then a second message
  from the same sender and no second reply; both blocks read that the
  window reported nothing.

- Every block written for this file — `captions`, `watch`, `deckfind`
  and `signature` — has passed under Xvfb in a Linux container, and the
  engine suite stands at 922; the Windows gate is run at release time.
