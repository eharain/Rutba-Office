The rest of WordArt's warps, a picture watermark, printing from what the file keeps, and a tile for every picture the window can draw.

## WordArt

- **More warps**: Shape Format → Text Effects → Transform → More gives
  twenty of Office's warps, in Documents, Worksheets and Presentations:
  the waves and double waves, Inflate and Deflate (top, bottom or both),
  the slants, triangles, chevrons, fades and curves. Each stretches the
  words across the box between its two curves, a letter at a time, its
  uprights kept upright as Office keeps them, and is saved as Office saves
  it. More shows as pressed while one is on.

## Documents

- **Picture watermark**: Design → Watermark → Picture watermark puts a
  picture from this computer behind the words on every page, washed out
  and centred inside the margins. It is saved in the header as Word saves
  one, so Word shows it too, a document Word made with one opens with it,
  and it is printed and drawn in the PDF. Words chosen afterwards replace
  it, and Remove watermark takes it off.
- **Print shows the document's own page**: File → Print starts from the
  document's paper, orientation and margins rather than from a default, and
  a change there changes the document, as Word's Print does. A3 and A5 can
  be chosen as well as A4, Letter and Legal.

## Presentations

- **Print keeps its choices in the deck**: full page slides, notes pages or
  a handout of so many slides to a page, and a frame round each slide, are
  kept where PowerPoint keeps them, so the next print opens on them, here
  or in PowerPoint.

## Pictures

- **A tile for a picture the system has no thumbnail for**: an SVG, an
  AVIF or a WebP showed the kind's icon where the system made no
  thumbnail; the window now draws the picture at the tile's size and keeps
  it for the next visit, as it draws a clip's frame.

## Fixed

- Pictures on Linux: every photo was decoded whole on the main process to
  make its tile, and a 40-megapixel one held every window for a second a
  tile; only a small picture is shrunk there now, and the window draws the
  rest off its own thread.
- An old Word, Excel or PowerPoint file cut short inside its first 512
  bytes was refused with a programming error; it is refused in a sentence
  saying it was cut short.
