Rutba Office 2.24.1 fixes adding an already locked folder to the Locker and four faults in Documents. From this version the releases are full releases, and the beta label is gone from the window title and Home.

## Locker

- **A folder that is already locked is recognised when you choose it.** Add folder used to offer to lock it, then say the password was wrong before you had typed one. It now says the folder is already locked and asks for the password that locked it, or its recovery key. Nothing in the folder changes while you do, and plain files in it stay unlocked until you lock them.
- **A damaged key file is left alone.** If a folder's key file cannot be read, the Locker says so and does not add the folder. Before, it could write a new key file over the damaged one.

## Documents

- **Numbered lists.** Tab at the start of a numbered item moves it a level in. It used to type a tab two letters along, and letters typed on a numbered line landed that far from the caret.
- **Tracked deletions.** The struck-out words no longer count when the caret is placed after them, so typing over a second word on the same line goes where you typed.
- **Table of contents.** With the caret in a heading or after one, the table landed inside a heading and took that heading's words and style. It now goes after the paragraph the caret is in. Update Table is fixed in the same way.
- **Page numbers in a table of contents.** A line that only just fitted no longer sends its page number onto the next line.

## Releases

GitHub now shows the newest release as Latest. Installed copies update as they did.
