Rutba Word is now Documents, and Presentation is now Presentations (plurals, beside Worksheets, Contacts and Pictures), and an updated copy keeps its pins, its defaults and its files' icons.

## Names

- **Documents and Presentations.** The two apps take the names the others
  already have: the place where everything of a kind lives. Mail and
  Calendar stay as they are, each the one place for all of its kind, and so
  do Image and Video for now.
- **Everything already set up keeps working.** A pinned Rutba Word on the
  taskbar opens Documents; `.docx` and `.pptx` still open in the same apps
  and wear the same icons; a window opened from a file is the same window.
  The names a person reads changed (the window titles, the launcher, the
  Apps menu, the taskbar's names, the installer's descriptions), and the
  keys the operating system files them under did not.
- **One list of names.** The Apps menu and the sentence a window says when
  it is handed the wrong kind of file ("…Open it in Documents.") carried
  their own copies of the names; they read the suite's one list now, so a
  name cannot be changed in one place and stay old in another.
- The launcher's New button names what it makes: "New document", "New
  workbook", "New presentation".

## Housekeeping

- The gaps list in `docs/GAPS.md` says what is true now: encrypted Office
  files have been read and written since 1.27.0, Mail's search is indexed
  per account, Calendar and Contacts are built and only their sync with a
  server is missing, and 129 of the 257 unbuilt controls remain.
- The steps before a release add the upgrade: the new installer run over
  the previous release, whose first start is the one a person gets after an
  update, where 1.28.0's window once stayed hidden.
- The PDF writer's, drawing's, editing's and doc-view's notes no longer
  describe a dependency the suite does not have or repositories the code no
  longer lives in.

## Proven, not promised

- `tests/app-names.test.js` pins the nine names, that each full name is the
  brand and its short name, and that the keys under them (`word`, `slides`,
  and the apps that own `.docx`, `.xlsx` and `.pptx`) have not moved.
- A window check (`RUTBA_VERIFY_ONLY=names`) opens Documents and
  Presentations and reads their titles, the launcher's cards and its New
  button, and the Apps menu.
- The install test now finds the Documents window under either name, so an
  older installer can still be put to it.
