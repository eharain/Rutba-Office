A consolidation release: what a reading of 1.26 to 1.29.10 found, put right across every app; ratings, tags and folder counts in Pictures; and the gate's own counts on the record.

## Pictures

- **Ratings and tags**: a picture is rated one to five stars from the
  details, or with the keys 0 to 5 as Windows Photos takes them, and tagged
  there. Both are kept on this computer by the file's path and never
  written into the picture. The stars show on its tile, the filter finds a
  tag as well as a name, a rating filter keeps so many stars or more, and
  Sort → Highest rated puts the best first.
- **A folder's tile says how much it holds** before it is entered.
- **Subfolders** searches the folders inside the one open, nearest first,
  for a name or a tag.

## Every app

- **Dialogs keep focus as a dialog should**: focus goes into a dialog when
  it opens, Tab and Shift+Tab go round inside it rather than into the page
  behind, focus goes back to what opened it when it closes, and Escape
  closes the top dialog only. What's New and About are dialogs too now, the
  password field's Show button can be reached with Tab, the comment
  threads' and the Selection pane's icon buttons have names, and an
  export's progress is read out as it changes.
- **Opening a file no longer stills every window**: the file is read and
  unzipped off the main process, so a large workbook or a file on a slow
  drive leaves mail and the other windows answering.
- **A drag whose mouseup is lost still ends**: the window left mid-drag, or
  the button let go outside it, no longer leaves a sheet scrolling or a
  picture following the pointer.
- **What a file names is not opened on its say-so**: a letter's recipient
  list is attached only after you are asked, as Word asks, and never from a
  network share, since reading a share hands it this computer's Windows
  sign-in; Refresh does not read a query source on a share that only the
  workbook names; and a program asked to be opened from any window is
  warned about from the main process.

## Fixed

- Documents: a document longer than five hundred pages printed and exported
  only its first five hundred; it lays out whole.
- Documents: Accept All and Reject All left an inserted or deleted table row
  marked, or kept it as an empty row, and passed over the headers, footers,
  footnotes and endnotes; they reach all of them now, and undo puts them
  back. A change made over several runs or paragraphs is saved with an id
  for each piece, as the schema asks.
- Documents: Update all left a table's = fields alone where Word wrote them
  as complex fields, and showed 10 where the field asked for 10.00; both
  forms are worked out, and a number picture is honoured however it is
  written.
- Worksheets: Power Query turned a quoted "007" and a split "A-007" into 7;
  the zeros are kept.
- Worksheets: Fill Series with a step that never reaches its stop filled
  ten thousand cells; it is refused. A series passes over the cells a merge
  hides.
- Worksheets, Documents, Presentations: a control character in a cell or a
  paragraph, pasted from a terminal, was written as it was and the file
  called damaged; it is left out.
- Presentations: Export to Video decoded every slide before the first frame
  (about 1.6 GB for two hundred slides at 1080p) and left its recorder
  running when a slide would not draw; each slide is drawn while the one
  before plays, and everything is let go however the export ends.
- Presentations: Record kept the microphone's raw samples; a quarter of that
  is kept now. A second press while the microphone opens is not a second
  recording, and closing the window or the Record Sound box while it opens
  turns the microphone off.
- Presentations: a cameo whose camera stopped asked for it three times in a
  second and a half, so a camera another program held for a moment left it
  blank; it keeps asking for about nine seconds.
- Presentations: Find Text counted a match split across two runs that
  Replace Text then left alone; the two agree.
- Presentations: every picture in a deck was held twice, and a picture whose
  bytes changed (a 3D model turned) kept its old copy too; each is held
  once.
- Mail: Move to, the junk filter and rules rewrote a folder's index for each
  message, tens of seconds for a few thousand; they write it once.
- Mail: a message the server marked as junk was let in on a Safe Sender's or
  a contact's name, which anyone can write; that name now counts only when
  the server also found the message really came from them.
- Mail: the store kept every folder it had ever read parsed in memory; it
  keeps sixty-four.
- Calendar and Contacts: each change rewrote the whole file, photos and all;
  a burst of changes is one write.
- Home: the Recent list looked for each of its files in turn, so a lost
  network drive held the window; it looks for them all at once and waits on
  none for long.
- Pictures: a folder of thousands was listed one file at a time on the main
  process; it is listed sixty-four at a time without holding it. The
  thumbnail queue keeps the newest two hundred tiles waiting, not every tile
  ever scrolled past, the kept thumbnails are trimmed to 400 MB, and a
  window keeps the frames of three hundred clips rather than every clip it
  showed.
- A file the windows write (an exported video, an edited picture) is written
  beside itself and renamed over, as documents are saved, so a failure part
  way leaves the old file.
- Merged letters, labels, a comparison or a photo album that no window took
  stayed in memory for the life of the app; they are let go after ten
  minutes.

## Checked

- The fuzzer now damages the old-format files as well as new ones (Word,
  Excel and PowerPoint 97-2003 and 95, and the password-protected ones),
  judges an answer by the error it was made from, and stops a file at two
  seconds: 5,400 damaged files, every one opened, asked its password or
  refused in a sentence. The ZIP reader it caught reading past a damaged
  archive's end checks each record first.
