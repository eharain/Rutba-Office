Rutba Office 2.13.1 fixes Data Files' start screen, which 2.13.0 cut off at both ends on most screens.

## Data Files

- **The start screen scrolls.** With twenty-five sample businesses the
  list is taller than most screens, and 2.13.0 centred it in a window that
  did not scroll, so New Database, Open, Recent and the ready-made
  databases sat above the window and the last samples below it. The screen
  now scrolls from New Database at its top to the last sample at its foot,
  and a short list is still centred.
