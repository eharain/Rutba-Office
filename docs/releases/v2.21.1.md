Rutba Office 2.21.1 fixes faults found in 2.21.0. Import in Contacts and Calendar said "ENOENT" for any file chosen in the Open box, and now brings the file in. In Data Files, a table linked to a worksheet with a totals row showed its dates as numbers, and its sums carried long tails of digits. In Pictures, a drawing kept as an EMF or a WMF showed the picture icon on its tile, and Edit did nothing on the picture Pictures was opened with.

## Data Files: tables linked to a worksheet

- **Dates stay dates.** A column of dates with a row such as Total at its
  foot was read as text, so each date showed as the number Excel keeps it
  as: 46027 instead of 2026-01-05. Each date is now read as a date, and the
  Total row keeps its word.
- **Sums as the sheet shows them.** A cell that adds other cells, such as
  a week's takings, is read to the 15 figures Excel shows: 3588.39, not
  3588.3899999999994.

## Data Files: the car dealer sample

- **An offer to print, every day.** The car dealer's Part-exchange
  valuation prints the valuations still open, and on some days the sample
  was made with none left open, so it had nothing to print. The sample now
  always has a customer weighing an offer.

## Pictures

- **Drawings on their tiles.** Windows gives no small picture for an EMF
  or a WMF, so Pictures draws the tile itself, and it could not read the
  drawing it was given. The tile showed the picture icon. In the grid and
  in the strip along the foot of the window, an EMF's or a WMF's tile now
  shows its drawing, as an SVG's does.
- **Edit on the first picture.** Opened from File Explorer on a photo,
  Pictures' Edit on that same photo only brought Pictures back to the
  front. It now opens the photo in Image, as it does for every other
  picture in the folder.
- **A folder of folders.** A folder holding only other folders said
  "nothing here" and offered All 0 beside its folders. It now says how
  many folders it holds, with no kinds to choose between.
- **A path with forward slashes.** A picture opened by a path written as
  D:/Photos/beach.jpg read "0 of 12" and its stars and tags did not show
  on its tile. It now reads as the same picture opened from File Explorer.

## Mail

- **Import mail fits its box.** With an Outlook profile holding two data
  files or more, each file's row under the account ran past the side of
  the Import mail box, so the box scrolled sideways and each file's size
  was cut off. The rows now end where the list does.

## Contacts and Calendar: Import

- **The file you choose comes in.** Import in Contacts and in Calendar,
  from the ribbon, Ctrl+O, the app menu's Open or the empty page's Import,
  read only the drive letter of the file chosen and said "ENOENT: no such
  file or directory" instead of bringing its cards or events in. A .vcf,
  .csv or .ics chosen in the Open box now comes in. Opening one from File
  Explorer always worked.
- **Search contacts works.** Typing in "Search contacts" left the box
  empty and the list as it was. What you type now shows in the box, and
  the list keeps only the cards that match it.
