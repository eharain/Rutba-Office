A link on a slide's words.

## Presentation

- **Insert → Link.** A web address on the selected shape's words — every
  run, each keeping its look — written as PowerPoint writes one, an
  External relationship on the slide and `hlinkClick` on the runs; drawn
  underlined in Office's link blue; Ctrl+click on the shape follows it,
  and the shape says so when the pointer rests on it. Editing the words
  keeps the link, which an edit used to drop. Ctrl+K opens it. The button
  was greyed out.

## Proven, not promised

- One engine test puts an address on a two-run box, finds every run
  pointing at the slide's External relationship with its look kept, reads
  the address back through a save, edits the words as the window does and
  finds the link kept, and takes it off. Two window checks put an address
  on the pasted box from the ribbon, find it drawn and offered to follow,
  and read the run and the relationship in the saved file (`clip`).
