Scripts in Worksheets that run on this computer, Merge and Append in Power Query, Show Changes for decks, and a mail merge that keeps its recipient list's ticks.

## Worksheets

- **Automate → scripts**: New Script and All Scripts open the Code Editor,
  with scripts in the shape of Excel's Office Scripts (`function
  main(workbook)`), kept on this computer, each to run, edit, save or
  delete. A script reads and writes ranges by address, values, formulas and
  number formats, sets bold, italic, colours, fills, sizes and alignment,
  adds and renames sheets, and logs to the editor. It runs in a worker of
  its own that can reach nothing, not the network and not a file, on a
  snapshot of the workbook; what it did comes back and is applied as one
  undo step. A script that fails changes nothing and says why, and one that
  runs on past fifteen seconds is stopped.
- **Record Actions** turns what you type and format while it is on into a
  script.
- **Power Query → Merge Queries** joins each row to the rows of another
  table or query whose key matches the picked column (Left Outer, Inner,
  Left Anti or Full Outer), bringing in the other's columns; **Append
  Queries** puts another table's or query's rows after the query's own. A
  query may read another query's result, run afresh on Refresh All.

## Presentations

- **Review → Show Changes**: a deck opened again shows what is different in
  it since it was last open on this computer, as when it comes back changed
  from a shared drive or by e-mail. A toast says how many slides differ and
  who saved it last, the strip marks them, and the Changes pane lists each
  slide added, removed, moved or changed, naming the shapes added and
  removed, the words changed and the shapes moved. A click goes to the
  slide; Dismiss clears the list.

## Documents

- **Mail merge keeps Edit Recipient List's ticks and sort** in the
  document, so the same people are left out when the letter is opened
  again, even if the list has moved its rows about.
