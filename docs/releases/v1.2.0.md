The release where every button was pressed.

1.1.0 shipped ribbons whose buttons did not work. Not "worked badly" — Word's
font, size, colour, indent and style controls each sent a key the engine does not
listen for, so they pressed and did nothing. Worksheets could not be formatted
from its toolbar, and a click on an empty cell selected nothing. The checks did
not catch any of it, because they drove the engines through operations and never
clicked a button. This release fixes what was broken and changes how the suite
is verified so it cannot ship that way again.

## What was wrong, and is fixed

**Word**

- Every font, size, colour, highlight, indent, spacing and style control now
  reaches the engine — and the page paints the result. A colour never showed
  before (the painter read a key the engine does not send); 12 pt drew at
  two-thirds size (pixels for points); centred, justified and indented
  paragraphs applied to the file and painted nowhere.
- Pressing **Bulleted list** crashed the page. It makes a list now.
- A table inserted from the ribbon looked like a stack of plain lines. It is
  drawn as a table, every cell still editable.
- **Insert → Picture** called a command that no longer existed. It opens a file,
  puts the picture in the document, and — the part that was also missing — draws
  it on the page. Charts and shapes ride the same path and are drawn too.
- Page size, orientation and margins use the engine's own names, so they work.

**Worksheets**

- Clicking an empty cell selects it. The engine deliberately does not emit empty
  cells (a sheet is mostly empty), so a click on blank grid landed on nothing;
  the grid now finds the cell under the pointer from its geometry.
- Bold, italic, underline, font, size, colour, fill, borders, alignment, wrap
  and number formats all paint. The cell painter read flat keys the engine never
  sends; it reads the engine's own shape now.
- Borders send edges; the chart menu offers only kinds the engine draws; the
  shape menu offers only shapes that exist.

**Everything else**

- A toolbar press no longer takes focus from the editor, so the selection a
  button acts on is still the active one. Dropdowns still take focus, because a
  dropdown that cannot take focus cannot open.
- Video: the scrubber set the playhead and then read it straight back from the
  media element before the seek had landed — so Split and Trim cut at 0, which
  is no cut. Fixed, with the playhead no longer snapping back mid-drag.
- Presentation: a "Shape" that inserted a text box is gone; the Design tab holds
  the deck's real size and the three layouts instead of disabled placeholders.

## How this is verified now

`npm run gate` still runs 577 engine tests, 9 editing checks and 8 window
captures — and now **86 application checks**, 35 of which select words on the
real page, press the real ribbon buttons and menus, fill in the real dialogs,
and read what the page paints:

- bold drawn at weight 700, 18 pt drawn at 24 px, red drawn as rgb(224, 49, 49)
- a paragraph centred, a list made, a heading applied, a table inserted and
  drawn as one, a page turned landscape, a picture inserted and drawn, undone
  and redone
- a click on empty C7 selecting C7, typing filling it, bold painting bold, a
  fill painting amber, borders painting a border, the Freeze dialog freezing the
  top row
- a slide added from the menu, a text box placed, notes saved, the slide
  deleted; the picture viewer rotated and advanced; the image editor's rotate,
  flip and reset; a clip split at the playhead
- a message composed, sent to the outbox with an undo, taken back and reopened

Each of those found something on its first run. None of them can be passed by
an engine that works behind a button that does not.

## Also in this release

Everything from 1.1.0 — the mail client that names the trackers in a message,
sign-in to Gmail and Outlook.com, rules that show their working, a search index,
a Markdown editor that gives a README back unchanged, presenter view, and the
one honest request outward. See the [1.1.0 notes](https://github.com/eharain/Rutba-Office/releases/tag/v1.1.0).
