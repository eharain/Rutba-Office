Footnotes and endnotes: inserted, reworded, deleted, undone.

1.3.0 showed a document's footnotes. This release lets you write them — the
second most common reason (after track changes) a document had to go back to
Word.

## What is new

- **References → Insert Footnote / Insert Endnote.** A dialog takes the words;
  a raised number appears at the caret and the note under the body (an
  endnote at the end), numbered by where its reference falls — insert one
  earlier and every later number moves, as in Word.
- **Rewording.** Double-click a note to change its words; the number and the
  reference stay where they are.
- **Deleting.** The reference is one character of the text, the way Word
  counts it, so Backspace removes it and the note leaves the page with it.
- **Undo** steps back through all of that, notes part included: undoing the
  first footnote a document ever had restores an empty part, not an orphan.
- The paragraph carrying a reference stays **editable** — type around the
  number freely. Before, a paragraph with a footnote was read-only, because
  the rebuild could not carry the reference; now the reference is a run of
  its own and the rebuild writes it back.
- A document with no footnotes part gets one written the way Word writes it,
  with the separator entries Word expects at ids −1 and 0, its content type
  and its relationship.

## Verified

- 590 engine tests (one new, walking the whole lifecycle: insert, type
  beside, reword, delete, undo four steps, endnote part creation).
- 100 application checks: the References button, the dialog, the number on
  the page and the words under the body.
