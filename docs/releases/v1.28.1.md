A release of fixes: a file dragged onto a window opens again, a save that cannot finish leaves the file as it was, Mail keeps a stranger's attachment in its folder and a password off an open line, Worksheets' formula bar amends what it shows, and an invitation that repeats on a day that never comes no longer freezes the suite.

## Everywhere

- **A file dragged onto a window opens again.** Electron 32 took away the
  way a window learnt where a dropped file lives, so every drop arrived with
  no path and nothing happened, in every app. A file dropped onto a message
  being written is attached to it, and is no longer also imported as a mail
  archive.
- **A save that cannot finish leaves the file as it was.** Save wrote
  straight over the file, so a full disk, a network share that went away or
  a crash halfway left half a document where the last good one had been.
  The new bytes now go to a file beside it and take its place in one step;
  a file that is read-only is still refused in a sentence. Save As over an
  existing file works the same way, and so does saving as OpenDocument,
  RTF, CSV, Markdown or text.
- **Closing with unsaved work always asks.** Choosing Save at the question,
  then cancelling the save or having it fail, left the question switched
  off, and the next close took the work with it.
- **A key does one thing.** Delete on a picked picture or chart in Worksheets also
  cleared the cells under the selection, and an arrow that nudged a shape in
  Presentation also changed slide.
- **Ctrl+R no longer reloads the window.** It sat in the View menu as
  Reload, where a Rutba Word user pressing it for Align Right reloaded the
  document from disk and left the edits behind. An installed copy no longer
  has Reload or Developer Tools at all.

## Mail

- **Save All keeps every attachment in the folder you chose.** An
  attachment's name is the sender's to write, and a name that climbed out
  of the folder — `..\..\Startup\run.bat` — was saved where it pointed. Only
  the last part of the name is used now, with the characters no system
  accepts, trailing dots and Windows' device names made safe.
- **Opening an attachment that is a program asks first.** One click on an
  `.exe`, a script, an installer, a shortcut or a disk image ran it. It is
  still yours to open; the window now says that opening it runs it.
- **A password is never sent over an open line.** An account on a plain
  IMAP port upgraded to an encrypted connection only when the server
  offered to, and anybody between the two could take the offer out. The
  upgrade is now required, as it already was for sending, and testing an
  account no longer leaves a connection open when the test fails.

## Worksheets

- **The formula bar amends what it shows.** A letter typed into the bar
  was taken as the start of a new entry and replaced the whole cell, so a
  value could not be corrected from the bar; Delete there cleared the cell,
  and Enter with nothing typed wrote an empty value over it. The bar keeps
  its keys now, as Excel's does.
- **Shift+F2 opens the note and nothing else**, where it also began an edit
  in the cell underneath the note.
- **Reading a workbook does not ask to save it.** Moving with Enter, Tab,
  Find Next or Go To marked the file as changed.
- **A dollar sign is saved as typed.** A sheet named `Sales $'000`, or a
  cell or formula holding `$&`, `$'` or `$$`, was taken apart on its way
  into the file: the sheet name became `Sales  sheetId=`, a cell kept its
  old value, `a $$ b` lost a dollar, and a formula's cached value nested a
  second cell inside the first.

## Calendar

- **An invitation that repeats on a day that never comes opens.** The 30th
  of February, or every seventh day from a Tuesday but only on Mondays, is a
  rule a calendar can write, and the search for its next day never ended:
  one such invitation opened from Mail froze every window. It now shows no
  occurrences, at once.

## Proven, not promised

- `npm test` runs the PDF writer's own suite too — 65 tests that sat
  outside the one folder the command looked in, so neither the gate nor a
  release had ever run them: 1,409 engine tests, six of which wait for
  `pdfjs-dist` to read the PDFs back.
- New engine tests: a save that fills the disk halfway leaves the file
  byte for byte as it was (`tests/document-service.test.js`), with moving
  by Enter, Tab, Find Next and Go To leaving a workbook clean; a hostile
  attachment name comes out as `run.bat` (`tests/mailbox.test.js`); a
  server on the loopback address that offers no encryption never hears a
  login (`tests/mail-imap-security.test.js`); the dollar cases above, down
  to the saved cell's XML (`tests/workbook-cells.test.js`); four rules that
  never land answer nothing in milliseconds (`tests/calendar.test.js`).
- New window checks: the formula bar amends "hello" to "hello!" and a bare
  Enter leaves it alone; a document dragged onto the launcher through
  Chromium's own drag, from the file on disk, opens in Rutba Word
  (`RUTBA_VERIFY_ONLY=drop`).
- The checks draw their windows in the light theme whatever the machine is
  set to: on a computer in dark mode the Format as Table check read the
  plain cells as painted and failed. 785 application checks.

## Under the hood

- The window bridge no longer offers the stored passwords and sign-in
  tokens, or renaming and copying files: nothing in a window used them, and
  a page that read a hostile document was one call away from them.
- `npm run dev` runs the suite from source and rebuilds the renderer and the
  preload on every save; the script pointed at a file that had never been
  written.
