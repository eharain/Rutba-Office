Sixteen buttons that used to be greyed out work now (Language, Gridlines, Set Up Slide Show, Monitor and the Window group among them). Text with a dollar sign in it is written as typed everywhere, and the suite lets go of what it held for a window when the window closes.

## Documents

- **Review → Language.** Marks the selected words as a language, or as not
  to be checked at all, the way Word keeps it (`w:lang`, `w:noProof`), so
  Word proofs them in their own language too. A right-to-left or East Asian
  language fills its own slot as well, so Urdu marked as Urdu is proofed as
  Urdu. **Set As Default** writes the document's language into its
  stylesheet's defaults. Spelling reads past French words and words marked
  not to be checked, and the page stops underlining them.
- **View → Gridlines.** A quarter-inch grid over the words' area of every
  page, inside the margins, to line drawings up by eye. It is on screen
  only, as in Word: it never prints and nothing of it is written to the file.
- **Review → Delete.** Removes the comment on the caret's paragraph, every
  comment in the document, or one picked in the Comments list (each with
  its replies, its range marks and the entries Word keeps for it in three
  other parts) in one step that Undo puts back.
- **View → Arrange All** stacks the open documents; **Side by Side** lays
  this one beside the one before it.

## Presentations

- **Review → Language.** Marks the selected box's words as a language, or as
  not to be checked, on their runs as PowerPoint keeps them. An edit to a
  box's words used to write every run back as US English whatever it had
  been; each run now keeps its own language.
- **Slide Show → Set Up Slide Show.** Who the show is for (a speaker, a
  window, a kiosk), whether it loops and plays its narration and animations,
  which slides it shows, how it advances and the pen's colour, written into
  the file where PowerPoint keeps them, and obeyed: the show starts on the
  range's first slide and loops inside it, a kiosk takes no click or key but
  Escape, and a show advanced by hand ignores its timings.
- **Slide Show → Monitor.** The screen the show plays on: Automatic, the
  primary screen, or any screen by name, kept for this computer. The window
  moves there before it fills the screen and goes back when the show ends.
  On Automatic with Presenter View, the show takes another screen than the
  presenter's.
- **Record → Save as Show** writes a copy as a `.ppsx`, which PowerPoint
  opens straight into the show. A file saved as a show, a template or a
  macro-enabled file is now labelled as one inside; Save As used to keep
  the label the file came with.
- **Insert → Symbol** puts its character where the caret was in a text box.
- **View → Arrange All, Cascade, Switch Windows** for the open decks, and
  **Move Split**: the arrow keys move the slide pane's edge and the top of
  the notes, Enter or Esc when done.
- Mark All as Read stays greyed and now says why: a deck keeps its comments
  but not who has read them.

## Worksheets

- **View → Arrange All** tiles the open workbooks; **Hide** puts a window
  away with its work kept, and a new **Unhide** brings it back. The last
  window on screen is never hidden.

## Underneath

- **Text with a dollar sign.** 1.28.1 fixed a workbook cell holding `$&`,
  `$'`, `` $` `` or `$$`; the same mistake took apart a document's comments,
  a deck's sections, comments and names, and an automatic reply's subject in
  Mail. Every one of them is written as typed now, and a test reads every
  engine's sources so the mistake cannot come back unnoticed.
- **Memory.** Every message opened in Mail held its pictures again, and
  every attachment saved or opened held the file again, until the suite
  quit. What the main process holds for a window is let go when the window
  closes, and the next message read replaces the last one's pictures.
- **Spelling** never puts a word with no Latin letter in it (Arabic,
  Hebrew, Chinese, Greek) to the English dictionaries, which could only
  call it wrong.

## Proven, not promised

- New engine tests: `tests/word-language.test.js`,
  `tests/deck-language.test.js`, `tests/deck-show-settings.test.js`,
  `tests/dollar-text.test.js`, `tests/literal-splices.test.js` and
  `tests/blob-store.test.js`, with more in the save-label and comment suites.
  `tests/act-cases.test.js` fails if an app names a command twice; the
  second would never run, as Worksheets' shape Arrange commands found out
  before this release did.
- Window checks press each new button and read what it did:
  `RUTBA_VERIFY_ONLY=` `gridlines`, `wordlanguage`, `decklanguage`,
  `setupshow`, `monitor`, `movesplit`, `saveshow`, `decksymbol`,
  `windowing` and `wordcomments`.
- A check run closes each block's windows when it is done. A full run used
  to hold every window to the end (about a hundred and forty renderers and
  fourteen gigabytes on a laptop) and now peaks under three. A check can
  answer the system's Open, Save and message dialogs, so the buttons that
  open one are checked too.
