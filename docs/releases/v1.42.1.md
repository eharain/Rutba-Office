1.42.0 as it was meant to ship: Rutba Office in Hindi, kashida for Arabic in print, and a week that starts where the language starts it, with installers that build.

## Fixed

- **The installers build again.** 1.42.0 asked the installer to speak Hindi
  as well, and the Hindi language file in the version of NSIS the build
  uses is broken (an unterminated string), so the build stopped and 1.42.0
  shipped no installers. The installer keeps the languages it had before,
  Arabic, Chinese and Japanese among them; on a Hindi or an Urdu Windows it
  shows in English.

## In this release, from 1.42.0

- **Hindi**: every word the windows show in Hindi, in Devanagari, with
  Indian digit grouping and a Devanagari digits choice; drafted by machine
  against a glossary, awaiting a native speaker's review.
- **Kashida**: Justify Low, Medium and High kept in the file and offered
  for a right-to-left paragraph; printed and saved as PDF with tatweels in
  the joins between letters.
- **Calendar's week** starts on the language's own first day: Saturday in
  Arabic, Sunday in Urdu and Hindi, Monday in English.

## Checked

- Nothing changed but the installer's settings; the engines, the windows
  and the checks are 1.42.0's, which passed before 1.42.0 was tagged.
