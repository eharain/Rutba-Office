1.44.0 with installers that build, and a plain sentence when an update check cannot finish.

## Fixed

- **1.44.0 had no installers.** Its tag was published, but the installer
  build stopped on a missing icon for Image's new project files (.rimg),
  so there was nothing to download. Copies of 1.43.0 then found a release
  with no update file in it and showed the updater's raw error in the About
  box. 1.44.1 is 1.44.0, the screen recorder, layers in Image and the Video
  preview's fixes included, with installers that build and a test that
  every file type the installer registers has its icon.
- **A failed update check is said plainly.** The About box gave the
  updater's whole HTTP exchange and stack. It now says what happened, in the
  window's language: a new release still being published, no connection to
  GitHub, or GitHub turning the check away for now, and otherwise a short
  first line of the error.
- Four words in the Urdu, Arabic and Hindi catalogues were listed twice;
  each is now listed once.

## Checked

- Engine tests: every associated file type has its icon on disk, and each
  kind of failed check reads as its own sentence with a one-line detail.
- The Windows installer and the portable copy were built from this commit
  before it was tagged.
- The performance budget is thirty seconds a step, from fifteen: on a
  four-core laptop the 100,000-cell recalculation takes 13 s quiet and 18 s
  straight after the engine suite, and twice closed the gate with nothing
  changed. A step gone quadratic still costs minutes.

## Gate

Run on Windows (x64) on 2026-10-12, before 1.44.1 was released: 2,253
engine tests, 2,247 passing and 6 skipped where a package they need is not
installed; 12 of 12 editing checks; 1,390 of 1,390 application checks; and
10 of 10 windows painted clean.
