Rutba Office 2.25.0 is the first full release: no pre-release flag on GitHub, and no beta label in the window title or on Home, in any language. Contacts, Calendar, Mail and Talk start to work together in it. Before it went out, the whole suite was read by independent reviewers three times, and the tests and the way they are run were reviewed too. It fixes what they found, most of it in the Locker, Mail, PDF redaction, Sheets and Documents.

## Talk

- **Invite by email.** Pick people from Contacts or type their addresses, and Talk sends each one an invitation from your own sending account in Mail, as a note from you that you can change. Each note carries the person's name, their own link to accept, and the way to get Rutba Office. With no Mail account to send from, Rutba sends it from no-reply@rutba.io within a daily and weekly limit, and the dialog says how many are left.

## Fixes

### Locker

- **A folder that is already locked is recognised when you choose it.** Add folder used to offer to lock it, then said the password was wrong before you had typed one. It now says the folder is already locked and asks for the password that locked it, or its recovery key. Nothing in the folder changes while you do, and plain files in it stay unlocked until you lock them.
- **A damaged key file is left alone.** If a folder's key file cannot be read, the Locker says so and does not add the folder. Before, it could write a new key file over the damaged one.
- **Deleting one version of a large file keeps the others.** A large file is kept in pieces, and Delete this version could remove every version of it.
- **A file another program holds open is never overwritten with zeros.** Locking it waits until the file can be removed. A wipe that is stopped part way no longer leaves zeros to be locked as the newest version.
- **Unsaved edits in an open copy are kept** when a lock or a close fails, when the drive is unplugged, or when the folder has been moved.
- **A file that grows or shrinks past the large-file size keeps its earlier versions.**
- **Key files keep every way in.** A replaced password or recovery key is retired, so it no longer opens files sealed after the change. A lost password can be reset with the recovery key. Another folder's key file is left alone.
- **Two versions** names each copy, so you can tell which one you are keeping.
- Only one Rutba Office at a time can use a profile, so two copies cannot lock the same folder against each other.
- The Locker's words are in Urdu, Arabic and Hindi.

### Mail

- **Search and archives work in an installed copy.** In 2.24.0 they did not.
- **Nothing is lost to a crash or a stopped step.** A message whose file was written but whose list entry was not now arrives the next time the folder is fetched. A folder rename, a move or a delete that is stopped part way no longer hides mail. A server that answers with a short or empty folder list no longer deletes local folders. A damaged line in the folder list or the message list gives back what it can instead of hiding the account.
- **Sending.** Undo is refused once the message is already going, rather than appearing to work while the message still goes. A message the server has accepted is never sent again. If a send fails, taking it back loses nothing: the words and the attachments stay. Recipients the server refused are named. Messages waiting in the Outbox are sealed like the rest of the mailbox.
- **Exports** keep attachments and headers, mark each saved attachment as a file from the internet, and say what they left out. A line in a message that starts with "From" no longer splits an mbox archive, and an archive with a quoted address in its separator lines reads back.
- A folder named Outgoing in 2.24.0 shows again after the update.

### PDF

Redaction removes the words under a mark in more of the ways a PDF can hold them:

- vertical text, text down a column, and fonts that give no widths;
- words in a form that inherits its text settings, or calls itself;
- patterns, soft masks and pictures under a mark, including a picture's metadata and its alternative text;
- layer names, form values and comments stored as streams, and replies to a removed comment.

A file built to make redaction hang or use up memory is stopped with a message. Search marks sit on the words they found, inside forms too.

### Sheets

- **Formulas are read as Excel reads them.** A formula with no array mark answers with one value, and shows the @ Excel shows. 658 formulas in three workbooks were checked against Excel 365's own answers and display.
- **Inserting and deleting rows and columns** moves formulas, conditional formats, validations, tables, filters, names and charts as Excel does. This was held to edits Excel made itself.
- **Tables.** Deleting every data row keeps one row, a calculated column is filled when rows are inserted, and the totals row follows.
- Stored results are kept for functions Office cannot work out yet and for links to other files, and Undo no longer clears them.
- Dates in 1904-based workbooks are right. .00 and fraction formats show as in Excel.
- Saving a .csv or .ods file keeps what the file held and says what it cannot keep. An .ods saved again no longer has Excel's @ written into its formulas.
- An .ods with a merged cell spanning past the sheet's edge, or thousands of formulas that each read the whole sheet, opens in seconds. Before, it could hang.
- A formula longer than Excel's 8,192 characters keeps the answer its file stored, and is not worked out again.
- A column of formulas that all read the same few thousand cells, such as SUMIF over a table, is worked out in a fraction of the time. 3,000 of them took eight seconds before.
- Files with errors such as #CALC! or #SPILL! in them now open in Excel.

### Documents

- **Numbered lists.** Tab at the start of a numbered item moves it a level in. It used to type a tab two letters along, and letters typed on a numbered line landed that far from the caret.
- **Tracked changes.** The struck-out words no longer count when the caret is placed after them, so typing over a second word on the same line goes where you typed. A tracked deletion keeps what it took, symbols and footnote marks included, so Reject brings it back.
- **Enter, Delete and Accept** were checked against fifteen edits Word made itself. Section breaks and symbols survive them.
- **Table of contents.** With the caret in a heading or after one, the table landed inside a heading and took that heading's words and style. It now goes after the paragraph the caret is in. Update Table is fixed in the same way. A line that only just fitted no longer sends its page number onto the next line.

### Slides

A long deck no longer trips an error while its thumbnails load. Deleted slides leave the file. A text edit keeps the formatting it did not touch. A copied slide gets its own charts and comments, so changing one leaves the other alone, and a column put into a table keeps the other columns in their proportions.

### Pictures, Video, Recorder and Live Broadcast

- **A video export that stalls no longer waits forever.** If the graphics encoder sends nothing for fifteen seconds, the export says so, then starts again on the processor. Before, a busy graphics chip could hold an export at the same second with no way to tell.
- Closing the Recorder while it records asks its own question. Before, Windows showed a "Save changes" box that held the window open.
- A disk that stops taking a recording ends the take, keeps what was written, and says so.
- An AI app that opens the Recorder and starts a recording straight away gets it. Before, the Recorder could finish reading in your own setup over the one the app asked for, and the recording never began.
- A PNG turned in Pictures keeps every pixel, sixteen-bit pictures and interlaced ones included.
- Files that claim to be far larger than they are are refused instead of stopping the window.
- Studio projects on a network share keep pointing at the share.

### Data Files

- A person whose role narrows what they may see can no longer design a query that reads past it.
- Long whole numbers and long keys stay exact, and a live table that was cut short says so.
- Linked databases check the server's certificate unless you accept one for that link.
- Secrets are not sent on when a server redirects to another address.

### Safety and updates

- Updates are signed with a key that is not on GitHub, and an installed copy refuses an update whose signature does not match.
- Saving a file with a password no longer holds up typing in other windows while it is written.
- A damaged Word, Excel or PowerPoint file whose parts cannot be unpacked is refused with a sentence that says so, not with the unpacking library's own words.
- Installing or updating never takes work: Cancel keeps the installed copy, and unsaved work is asked about before an update closes the window.
- Opening an attachment that would run as a program asks first, for more kinds of program than before, including the newer kinds mail is used to deliver and names that end in a space or a dot.
- Mail frames show only their own pictures, and a network path in a message can no longer make Windows send your sign-in to another computer.
- What a permission prompt asks about is shown in full.
- GitHub shows the newest release as Latest. Installed copies follow full releases only.

## Known limits

- Some Excel functions are not built yet (MMULT, MINVERSE, FREQUENCY, TREND, LINEST, GROWTH, NUMBERVALUE, ISREF, ISFORMULA, FORMULATEXT and CELL), nor the space and bracketed comma reference operators. A file's stored answer is shown until it is recalculated.
- A recovery key replaced in 2.24.0 still opens the files sealed while it was in use.
- If the Recorder's disk stops taking the recording, the message shows Windows' own words for the error.
