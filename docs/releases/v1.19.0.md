A floating text box prints beside the words, and a block of cells becomes a table.

## Worksheets

- **Format as Table.** Home → Format as Table, or Insert → Table, makes
  the selection — or, from one cell, the block of data round it — a table:
  a header row, banded rows if you ask, and a style Excel knows by name
  (light, medium, dark). The header row and the banding are painted at
  once, in this window's own palette, as tables from files already were;
  a header cell with nothing in it is given its column's name, as Excel
  does. The file carries it as Excel keeps a table — the table part with
  its columns and autofilter, the sheet pointing at it — so Excel shows the
  table too. One undo step.

## Rutba Word

- **A floating text box prints beside the words**, as it has shown on
  screen: a pull quote or a sidebar anchored at the left or the right is
  placed at its paragraph's top on that side, the lines beside it laid out
  shorter for as far down as it reaches, in print and PDF. It was drawn
  under its paragraph as a block. A box that would leave the lines no room
  stays under the words.

## Proven, not promised

- Three engine tests make a table from one cell and from a selection, read
  the part, the rels, `tableParts` and the paint, name empty and repeated
  header cells, number a second table, refuse a clash and undo one.
- Two window checks press Home → Format as Table, read the header row and
  the banding painted, save, and read the table back from the file
  (`RUTBA_VERIFY_ONLY=links`).

- One engine test anchors a box at the right and at the left, reads it as a
  float with the lines beside it shorter and none running into it, and
  prints it.

## Under the hood

- `paginate.js` places a `floatbox` fragment (side, top, size, fill, line,
  laid paragraphs) and adds it to the page's floats; `pdf.js` draws it
  through `drawTextBox` at the float's place.
