The release where Word opens the documents people actually send.

1.2.0 made every button work. This release is about what is on the page when
a real document is opened — a tender, a contract, a questionnaire — measured
the only honest way: the same file opened in Microsoft Word and in Rutba,
both photographed, the differences fixed one at a time. The corpus behind it
is 474 `.docx` files from public procurement: 473 open now (the last one is
not a zip archive), none takes longer than five seconds, and a 32 MB manual
that used to take 92 seconds opens in three.

## What was missing from the page, and is drawn now

- **The document's own fonts, sizes and colours.** Every document was drawn in
  Calibri, black, one size, because the stylesheet was read for pagination
  and never for painting — and fonts named through the theme (which is how
  Word names nearly all of them) were not read at all. The page now paints
  each paragraph from its resolved style: face, size, colour, bold, italic,
  caps, alignment, spacing before and after, line spacing, indents, shading,
  tab stops — with the theme's heading and body faces resolved, and direct
  formatting on a paragraph or run beating the style, as in Word.
- **Tabs.** No tab had ever reached the page: the text reader kept only what
  sat inside `<w:t>`, and a tab never does. Form lines ran their label into
  their value ("DATED[dd/mm/yyyy]"). Tabs are read, sized to the paragraph's
  own stops or its style's (left, centre, right and decimal, with dot,
  hyphen and underscore leaders), and a tab typed into a paragraph is written
  back as the element Word expects. Line breaks inside a paragraph are kept
  too, and a run of spaces is a run of spaces.
- **Cover pages and tables of contents.** Word puts both in a content control
  at the top of the body, and the reader treated every control as opaque —
  so the Leicestershire LMS tender opened on its second page. A body-level
  control's paragraphs are on the page now, read-only (the engine cannot
  rebuild a control, so the caret is kept out of one rather than allowed to
  make edits that vanish).
- **Text boxes.** A cover page is mostly text boxes: the title block, the
  contact details, the abstract. They are drawn in flow under the paragraph
  that anchors them, at the file's size, with the shape's fill (theme colours
  included, tints applied) and outline, their paragraphs painted exactly like
  the body's. Before, a text box's words were sometimes shown as body
  paragraphs and the paragraph carrying the box was lost.
- **Headers and footers** are drawn in the page margins, greyed the way Word
  greys them, with the page-number field resolved; double-click one to edit
  it. A title page shows the first-page band — and nothing at all when the
  file defines none, which is how a cover page has no running header.
- **Footnotes and endnotes.** The reference is drawn as a raised number in
  the body, numbered by where it falls, and the notes sit under the body with
  their own numbers. Paragraphs carrying a reference are read-only, so an
  edit can never orphan a note.
- **Paragraph shading and borders**, including a style's — the shaded title
  band, the rule under a heading.
- **Hyperlinks** are blue and underlined; **superscript and subscript** are
  painted (and can now be applied from the ribbon: x² and x₂ are buttons, not
  promises).
- **Watermarks.** "DRAFT" across every page is the header's WordArt; its words
  are read and drawn behind the body.

## What the page shows that print does not, yet

The printed pages and the PDF export are laid out by the paginator, which
places pictures and tables but not, yet, text boxes, footnotes or the
watermark — those are on the screen and not on paper. Inserting a footnote,
editing inside a content control or a text box, and a table of contents that
updates itself are not built; the ribbon says so on each button.

## Performance

- Opening a 3,000-paragraph contract took 25 seconds per frame: the frame
  asked the file for each paragraph's alignment again, per paragraph, per
  keystroke. It reads what the paragraph already carries; the frame takes
  380 ms.
- A table whose header row repeats on every page sent the paginator into a
  loop that ran the machine out of memory (4 GB) on an 81 KB document. It lays
  the table out in 144 ms now, and a runaway guard means no document can do
  that again.
- The document service no longer paginates on every keystroke — the editor
  draws from blocks and never read the pages.

## The Word ribbon

Every tab Microsoft Word has — Home, Insert, Draw, Design, Layout, References,
Mailings, Review, View, Help — with every group. What is wired is wired to
the engine; what is not is disabled with a title that says why, so the ribbon
never pretends. New this release: the Navigation Pane, the ruler, formatting
marks, the five view modes, Focus mode, zoom, Symbol, Date & Time, Change
Case, the Format Painter, Cover Page, Blank Page, Table of Contents from the
headings, Next/Previous Footnote and Show Notes, Document Properties, keyboard
shortcuts, the tracked-changes list, and x²/x₂.

## How this is verified now

- 589 engine tests (12 new, on a purpose-built fixture with a cover page in a
  content control, a themed text box, tab stops, shading, a border, theme
  fonts, character styles, footnotes out of id order, a first-page header and
  a watermark).
- 99 application checks that press the real buttons — every Word tab, the
  navigation pane, the marks, the view modes, Symbol, Date & Time, Change
  Case, the style box, the table of contents, superscript — and one that
  measures the page is centred in the window, because it was not: the app's
  one grid column grew to the ribbon's 2,372 px and the page was centred in
  that.
- Two tools for the comparison itself: `tools/compare-word.ps1` asks Microsoft
  Word to export a document as PDF (one Word per document, three minutes
  each, an unblocked copy so Protected View cannot wedge it), and
  `tools/pdf-pages.ps1` rasterises PDF pages with Windows' own renderer, so a
  page of Word's can be put beside a page of ours with nothing installed.
