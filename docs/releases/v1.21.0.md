A cell's words move in, and turn.

## Worksheets

- **Home → Increase indent, Decrease indent.** The two arrows move a cell's
  words in and out by one of Excel's indent units a press, each cell from
  its own indent, and never below none. Written as Excel keeps an indent —
  in the cell's alignment, beside a left alignment when the cell had none.
  Centring a cell drops its indent, as in Excel. The buttons were greyed
  out; an indent in a file was drawn and none could be given.

- **Home → Text orientation.** Angle anticlockwise, Angle clockwise,
  Vertical text, Rotate text up, Rotate text down, and Horizontal text to
  put it back: the words turn on screen and on the printed page, the row
  growing to hold them, and the file carries Excel's own rotation so Excel
  shows the same. The button was greyed out before.

- **Page Layout writes the file.** Margins, Orientation and Size on the
  Page Layout tab now write the sheet's own page setup — the one the print
  dialog and Excel start from — where until now they changed a note in the
  window that nothing read, so a landscape chosen there printed portrait.
  Print Titles repeats the top rows on every page (a row, two, three, or
  the selected rows from row 1), and Scale to Fit sets Width and Height to
  one page or automatic, and Scale to a percentage; all the rows down one
  page is new to the engine. The tab says what the file has now.

- **Page Layout → Breaks.** Insert page break puts one above the row and
  left of the column of the cell (only one of them at the sheet's edge, as
  Excel does), Remove takes it off at the cell, Reset takes them all away;
  the tip counts them. The file keeps them as Excel does, and the print
  dialog's page count and the printed pages start a page at each. The
  Margins presets on the tab are the print dialog's own three now, so a
  Normal chosen on the tab is Normal in the dialog.

- **Insert → Header & Footer.** What prints at the top and the foot of
  every page, with Excel's codes (&P page, &N pages, &A sheet, &F file, &D
  date, &T time; &L, &C and &R start the left, centre and right parts) and
  quick picks that add them. Kept in the file as Excel keeps them, so Excel
  prints the same; the three parts print left, centre and right. The
  button was greyed out, and the print dialog had no field for either.

## Proven, not promised

- Ten engine tests set an indent and read it beside the left alignment,
  step two cells from their own indents and stop at zero, keep a right
  alignment's indent and drop a centred cell's, write each of the five
  orientations and read them back after a save, take a rotation off, and
  undo both with the style table.
- Three window checks press Increase indent twice on A2 and read the words
  move in by nine pixels a press, pick Rotate text up and read the words
  standing on end with the row grown, save, and read the indent and the
  rotation back from the file (`RUTBA_VERIFY_ONLY=links`).
- One engine test fits all the rows on one page down and reads that back
  from the file. Two window checks pick Landscape, Repeat row 1 and Width
  → 1 page from the Page Layout tab, read the page setup change each
  time, save, and read the three back from the file (`links`).
- One engine test breaks a report at row 60 and counts a page more, writes
  a row break and a column break, reads them back in schema order, and
  resets them. Two window checks put a break at A3, read the sheet
  printing on two pages, save, and read the brk back from the file
  (`links`).
- One engine test writes a header and a footer, reads them back in schema
  order, prints the three parts with the sheet name in the centre and the
  page count at the foot, and finds a footer-less file prints no foot. Two
  window checks type both into the dialog from the Insert tab, read them
  back from the page setup, save, and read them from the file (`links`).

## Under the hood

- `setFormat({ indent, indentBy, rotation })` in `applyFormat` beside
  align, valign and wrap; `formatOf` and the frame's cells carry `indent`
  and `rotation`; the grid and the print page turn the words alone, not
  the cell.
