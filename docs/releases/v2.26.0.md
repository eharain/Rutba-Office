Rutba Office 2.26.0 opens a locked file from the Locker in memory, with no plain copy on the disk, and can keep a safety copy of a folder until you say all is good. Voices and languages are now add-ons you choose, Read Aloud is in Mail and in more of the apps, and Recorder, Video and Live Broadcast can read a title's lines aloud. 2.25.1 was not released on its own, and its fixes are in this release.

This note is also in [Arabic (العربية)](https://github.com/eharain/Rutba-Office/blob/main/docs/releases/v2.26.0.ar.md), [Hindi (हिन्दी)](https://github.com/eharain/Rutba-Office/blob/main/docs/releases/v2.26.0.hi.md) and [Urdu (اردو)](https://github.com/eharain/Rutba-Office/blob/main/docs/releases/v2.26.0.ur.md).

## Locker

- **A locked file opens in memory.** A document, workbook, deck, PDF or
  picture from the Locker is read out of its locked file into memory, and
  no plain copy is written anywhere. A film or a song plays straight from
  the locked file. Save seals the new version into the locked file.
- **Some files still open from a plain copy.** A document, workbook,
  deck, PDF or picture over 1 GB, kinds that are read from the disk
  (HEIC, TIFF, PSD, MOV and MKV among them), files of Mail, Calendar,
  Contacts, Data Files and the Recorder, and kinds another program opens,
  open from a temporary plain copy as before, and the window says so in
  one line: that copy is not locked.
- **A file from the Locker is saved only back into it.** Save As, Export
  and Redact to a place outside the Locker are refused, and so are Export
  as PDF, Compare, a mail merge's letters and e-mails, and opening an
  embedded object in another program. To have a copy somewhere else, use
  Unlock or Send in the Locker. Printing a locked document works, with
  nothing written to the disk. Video plays a film from the Locker but does
  not edit or export it.
- **Older formats.** A locked .doc, .xls, .ppt or .htm opens with a line
  saying that saving makes a new file in the current format beside it, in
  the same locked folder: Budget.xls makes Budget.xlsx, or Budget
  (2).xlsx when that name is taken. The old file is left as it was.
- **A lock seals what is open.** When the Locker locks, by Lock now, the
  computer going to sleep or locking its screen, or Office closing, each
  file open in memory is sealed with its unsaved work, and its window
  closes without asking. The sealed copy is kept up to date as the app
  autosaves, so after a crash the work is offered back too.
- **Reopen the files that were open.** After the next unlock, the Locker
  offers the files that were open, with the ones holding unsaved changes
  marked. One you reopen opens with its unsaved work, still marked as not
  saved. Leave them closed asks first when that drops unsaved changes.
  When two copies of one file's unsaved work are offered, the newer opens
  as the file and the older as a new file beside it, such as "Budget
  (2).xlsx", and the Locker's window says so.
- Closing the Locker's window and the idle lock still wait while a file
  from the Locker is open in a window.
- **A profile on a share or a portable drive.** When Office's profile is
  on a network share, or on a drive formatted exFAT or FAT, the Locker's
  window says that a temporary plain copy made there is not kept to your
  account alone while its file is open. Nothing is refused, and the
  locked files stay locked.
- The Locker no longer makes previews of locked pictures.

### A safety copy until you say all is good

- **Keep a safety copy until I say all is good.** When you lock a folder
  for the first time, the Locker can first keep a copy of its plain files
  in Office's own folder on this computer. The box is ticked and
  suggested for your first folder. The Locker checks the room on the
  drive first, and reads the copy back before any plain file goes.
- **The copy is not locked with your Locker password.** Anyone who signs
  in to your Windows account can restore it, and the window says so. Your
  Windows password protects it if the disk is taken.
- **All good, remove the safety copy.** The Locker reads back every file
  of the copy, checks the locked folder against it, and tells you what
  does not match before anything is removed. After 7 days the folder
  reminds you the copy is still kept, and after 30 days each unlock asks
  whether to remove it. It is never removed without asking.
- **Restore from the safety copy** works from the password screen too,
  since the copy is not locked with the password. It writes the files,
  unlocked, into a new folder inside the one you choose, and changes
  nothing already there.
- A file that keeps changing while the copy is made can be left plain
  while the rest of the folder locks.
- Removing Rutba Office keeps the safety copies, and their key, unless
  you tick the box that removes them.

## Mail

- **Read aloud.** On the Home tab, Read aloud reads the open message: who
  sent it, its subject, then its words. The message it answers, quoted
  below it, and the signature are left out, a web address is read as its
  site alone, and a forwarded message is read as what it forwards.
- **Play all and Play unread** read every message in the list, or its
  unread ones, in the list's order. The list's filter and its search
  decide which messages those are, and a conversation's messages are read
  one after another. Each message shows in the reading pane as its turn
  comes.
- **Marked read only when read to the end.** Play all and Play unread
  mark a message read once it has been read to its end. One skipped or
  stopped stays as it was, and so does one you mark by hand while it is
  read. Read aloud on the open message marks nothing.
- The reading bar has play and pause, a sentence back and forward, the
  message before and the next, speed and voice, and says which message
  of how many it is reading. Another account, folder, view or search
  stops the reading.

## Read Aloud and voices

- **One reader for the apps.** Read Aloud reads a sentence at a time with
  a bar to pause, go back or forward a sentence, change the speed and
  choose the voice. It uses the Windows voice unless you choose a voice
  you have added, and the voice you choose is kept for each language.
- **In Documents**, each sentence is selected as it is read.
- **In Slides**, Read Aloud reads this slide, its notes, or the slide and
  then its notes.
- **In PDF**, Read Aloud reads the words of the pages from the one shown,
  and shows each page as it reads it.
- While no voice is added, an icon beside the bar opens Voices and
  languages.

## Recorder, Video and Live Broadcast

- **Spoken lines in Video.** A title's or a caption's words can be read
  aloud line by line onto the timeline. Each line becomes its words as a
  text clip and its voice as a sound clip under it, one after another.
  Choose Show the text, Play the voice, or both, with the voice and its
  speed. Read again makes each line once more with the voice and speed
  you have now. The voices are sound files kept in the project's Made in
  Video folder, under Spoken lines.
- **Spoken lines in the Recorder and Live Broadcast.** A title's lines are
  read aloud one after another into the recording and the stream, each
  shown on the title's band while its voice plays. The voice goes into
  the recording, not to your speakers, so a microphone does not pick it
  up a second time. With the sound off, the window says the voice is not
  in the recording or the stream.
- Lines read while recording, in a Recorder opened from Video, land on
  Video's timeline line by line with the takes.
- Spoken lines use only voices added in Voices and languages, because the
  Windows voices give no sound that can be recorded. Until one is added,
  an icon in the section opens Voices and languages.

## Voices and languages

- **Voices and languages** is a new window, in each window's menu below
  Language. It lists the voices and languages offered for this version,
  and adds, pauses or removes them. Speech is made on this computer, and
  what it reads never leaves it.
- **Added for you alone.** Voices and languages are added to your own
  folder, even when Office is installed for everyone on the computer, and
  each person adds their own. A portable copy keeps them in a folder
  beside it.
- **With no network**, a voice or language can be added from its .zip
  file, brought from another computer, with Add from a file.
- **Drafts are marked.** No language pack has been reviewed yet, so each
  is marked "(draft)" wherever you choose a language.
- **The installer offers your computer's languages.** On a first install,
  when the computer uses a language Office has a pack for, a Languages
  page has a box for each, ticked. Office adds them at its first start
  once the computer is online. Without that choice, Home offers them
  once. Urdu, Arabic and Hindi are still built into Office and are not
  offered there.
- **Back to English in one click.** While a window is in another
  language, its title bar has a globe marked EN. One click shows the
  window in English at once, with its document, and the windows you open
  after it are in English too. In English the same button goes back. A
  window with changes not saved is not opened again: it asks you to save
  first.
- **An update waits for your voices and languages.** When a new version
  is out but a voice or language you use is not ready for it yet, the
  update waits and says which ones it is waiting for, with Update anyway
  to take it now. This also holds for Urdu, Arabic or Hindi if a later
  version no longer carries the one you use built in, until its pack is
  ready.
- Before an update downloads, the voices and languages ready for it come
  down first, shown as part of the download.
- Removing Rutba Office asks whether the voices and languages you added
  go too, with the room they take. The answer starts at No, and an update
  never asks.

## Fixes

### Locker

- **A path with a space in it.** A document opened from the Locker was
  not seen as open in its window when its path had a space in it, which
  it always has when the Windows user folder has one, such as
  C:\Users\Sam Khan, and often has when the file's own name does, such as
  "Staff handbook.docx". Locking then took the document's copy from under
  its window, and the window's next Save failed. Closing the Locker's
  window and the idle lock did not wait for the document to close. A
  closed document's copy stayed until the Locker was next locked, and
  until then Rename, Delete and Delete this version each said the file
  was open. Office now sees the document as open whatever its path holds.

### Mail

- **Delete takes the message you are reading.** Delete and the other
  message actions act on the message the reading pane shows. Before, a
  message just clicked, which the pane did not show yet, could be the
  one they acted on. The ribbon's message buttons are greyed while the
  pane catches up, and the pane's own buttons act on the message it
  shows.
- **A message that will not open** says so where it would have been,
  rather than leaving the one before it showing.
- **The right-click menu acts on the row you point at**, or on its
  conversation where the list shows conversations, even when that row is
  not open. Reply, Reply all and Forward from it keep the message you
  are writing in Drafts, open the row, and start once the reading pane
  shows it. In an archive opened in place, the row can be copied, not
  changed.
- Turning Safety off, from the top of a message or its right-click menu,
  holds to the message the pane shows.
- With the reading pane off, Reply, Reply all and Forward wait for the
  message to load, and are greyed until it has.

### Slides and Video

- **Export to Video never saves a video with no picture.** On a busy
  computer the recorder could give the sound and none of the picture: a
  file of the right length with nothing to see. The finished video is now
  looked at before it is saved, made again once if it has no picture,
  with a line saying why it starts again, and refused in plain words if
  the second has none either.
- Video's export that records in real time is looked at the same way
  before it is written. Cancelled while it is looked at, nothing is
  written.
- **Recordings that play to the end.** Export to Video, a slide's camera
  recording and a slide's recording from the Recorder were made as
  H.264 of a kind whose settings are fixed for the whole file. If the
  encoder started again part way with new settings, the picture after
  that point would not play. They are now made as H.264 that carries its
  settings at each key frame, where the computer can record it, so every
  frame plays.

### Documents

- **A damaged .doc file.** A Word 97-2003 file (.doc) whose table of
  list overrides was damaged to say it held four billion of them had
  Documents count them all: Office stopped answering and then closed. It
  now reads only the overrides the file has room for, and opens the
  document.

### Data Files: the cafe sample

- **Something to order, every day.** The cafe's Ingredients to order,
  and the Order list for suppliers printed from it, list what has run
  down to its reorder level. On some days the sample was made just after
  the deliveries had brought everything back up, so both were empty. The
  sample now always has an ingredient at its level on the day it is made.

### Removing folders

- **A link inside a folder is never followed.** When Office removes a
  folder, such as a profile, a mail account, a mail folder or one the
  Locker made, a link inside it to another folder (a Windows junction) is
  removed as a link, and the folder it points at is left as it was.
  Before, what the link pointed at could be removed with it. Voices and
  languages are removed the same way.

## Checks

Every window check now runs in a profile whose folder has a space in its
name, as a Windows user folder such as C:\Users\Sam Khan gives, so a fault
of this kind shows in any app. The Locker's checks for Lock now, closing
its window and the idle lock each failed on 2.25.0's code before the fix,
and pass with it. The checks of folder removal run on Node and also on
the runtime Office ships with, where a plain removal follows a link. The
check of Sheets' formulas against Excel's own answers reads dates the way
Excel read them when it answered, so it gives the same result on any
computer and in any year.
