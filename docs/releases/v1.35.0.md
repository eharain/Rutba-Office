Pivot Column and Conditional Column in Power Query, scripts that set widths and merge cells, and a Save that no longer holds every window while it compresses.

## Worksheets

- **Pivot Column**: the Query Editor turns each value of a column into a
  column of its own, filled with another column's values summed, counted,
  averaged, at their least or most, or not added up at all.
- **Conditional Column**: a new column whose value is what the first
  condition a row meets gives (if Region equals East then Home), or an
  otherwise value.
- **More of Office Scripts' calls**: a script sets a column's width and a
  row's height in points, autofits columns, merges and unmerges cells,
  strikes text through and aligns it to the top, middle or bottom. Record
  Actions now writes lines for widths, heights, merges, clearing, the rest
  of the font's look, and sheets added or renamed.

## Every document app

- **Save no longer holds the other windows**: the changed parts of a file
  are compressed off the main process, so saving a large workbook leaves
  mail and the other windows answering. An edit made while a save runs is
  kept for the next save rather than half included.

## Fixed
